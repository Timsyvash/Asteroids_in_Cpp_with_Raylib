# Asteroids in C++ (Raylib)

Клон класичної аркадної гри **Asteroids**, написаний мовою C++ з використанням графічної бібліотеки [Raylib](https://www.raylib.com/).

## 🚀 Особливості гри
- 🛸 **Фізика космосу**: реалістичний поворот корабля, інерція руху та гальмування за рахунок тертя.
- 🌌 **Screen Wrap**: при вильоті за межі екрана корабель і астероїди телепортуються з протилежного боку.
- 💥 **Система стрільби**: лазерні постріли за напрямком носа корабля.
- 🪨 **Астероїди**: завантаження та рендеринг текстур уламків.

## 🛠️ Вимоги та залежності
- **C++17** або новіший.
- **Visual Studio 2022** (або інша C++ IDE).
- Бібліотека **Raylib** (5.0+).

## 🎮 Керування
- **W** / **↑ (Стрілка вгору)** — Тяга двигуна (прискорення вперед)
- **A** / **D** або **←** / **→** — Поворот корабля
- **Space (Пробіл)** — Постріл лазером
